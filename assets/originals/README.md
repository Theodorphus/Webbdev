# Originalbilder

Källfiler som kunden levererat. De ligger utanför `public/` så att de inte
deployas eller går att nå via sajten. De optimerade WebP-kopiorna som faktiskt
används finns i `public/work/`.

- `cement/` → `public/work/cases/cement-*.webp` (se `public/work/cases/SOURCES.md`)
- `traffic/` → `public/work/cases/traffic-*.webp`
